WEBLOGIC - RECREATE DEMO CERTS WITH CORRECT PASSWORD
======================================================

STEP 1 - DELETE OLD FILES
---------------------------
  del %DOMAIN_HOME%\security\DemoIdentity.p12
  del %DOMAIN_HOME%\security\DemoTrust.p12

  Note: If any file not found - just continue to next step.


STEP 2 - CREATE DemoIdentity.p12
----------------------------------
Run as single line:

  keytool -genkeypair -alias DemoIdentity -keyalg RSA -keysize 2048 -validity 365 -storetype PKCS12 -keystore %DOMAIN_HOME%\security\DemoIdentity.p12 -storepass welcome01 -keypass welcome01 -dname "CN=%COMPUTERNAME%, OU=Demo, O=Demo, L=Demo, ST=Demo, C=US"


STEP 3 - EXPORT CERT FROM DemoIdentity.p12
--------------------------------------------
Run as single line:

  keytool -exportcert -alias DemoIdentity -keystore %DOMAIN_HOME%\security\DemoIdentity.p12 -storetype PKCS12 -storepass welcome01 -file %DOMAIN_HOME%\security\DemoCert.crt


STEP 4 - CREATE DemoTrust.p12
-------------------------------
Run as single line:

  keytool -importcert -alias DemoTrust -file %DOMAIN_HOME%\security\DemoCert.crt -keystore %DOMAIN_HOME%\security\DemoTrust.p12 -storetype PKCS12 -storepass welcome01 -noprompt


STEP 5 - VERIFY BOTH FILES
----------------------------
Verify Identity:

  keytool -list -v -keystore %DOMAIN_HOME%\security\DemoIdentity.p12 -storetype PKCS12 -storepass welcome01

Verify Trust:

  keytool -list -v -keystore %DOMAIN_HOME%\security\DemoTrust.p12 -storetype PKCS12 -storepass welcome01

Check that:
  - Owner CN shows your current machine name
  - Valid from shows today's date
  - Valid until shows 1 year from now


STEP 6 - START WEBLOGIC
-------------------------
  %DOMAIN_HOME%\bin\startWebLogic.cmd


======================================================
NOTES:
- Run ALL keytool commands as single lines.
- If keytool not recognized, run first:
    set PATH=%JAVA_HOME%\bin;%PATH%
- Password used for both Identity and Trust : welcome01
- Files created directly in %DOMAIN_HOME%\security\
- Do NOT start WebLogic until both files verified.
======================================================

WEBLOGIC - REPLACE EXPIRED PKCS12 CERTIFICATE ON WINDOWS
==========================================================

STEP 1 - FIND THE OLD KEYSTORE FILE
-------------------------------------
Open CMD and run:

  dir /s /b %DOMAIN_HOME%\*.p12
  dir /s /b %DOMAIN_HOME%\*.jks

Note down the full path and filename of whatever it finds.


STEP 2 - DELETE THE OLD KEYSTORE
----------------------------------
  del %DOMAIN_HOME%\security\identity.p12

(Replace identity.p12 with the filename you found in Step 1)


STEP 3 - GENERATE NEW SELF-SIGNED CERT
----------------------------------------
  keytool -genkeypair ^
    -alias %COMPUTERNAME% ^
    -keyalg RSA ^
    -keysize 2048 ^
    -validity 365 ^
    -storetype PKCS12 ^
    -keystore %DOMAIN_HOME%\security\identity.p12 ^
    -storepass Welcome1 ^
    -keypass Welcome1 ^
    -dname "CN=%COMPUTERNAME%, OU=IT, O=MyOrg, L=City, ST=State, C=US" ^
    -ext "SAN=dns:%COMPUTERNAME%"


STEP 4 - CREATE TRUST KEYSTORE
--------------------------------
Export the cert:

  keytool -exportcert ^
    -alias %COMPUTERNAME% ^
    -keystore %DOMAIN_HOME%\security\identity.p12 ^
    -storetype PKCS12 ^
    -storepass Welcome1 ^
    -file %DOMAIN_HOME%\security\demo.crt

Import into trust store:

  keytool -importcert ^
    -alias %COMPUTERNAME% ^
    -file %DOMAIN_HOME%\security\demo.crt ^
    -keystore %DOMAIN_HOME%\security\trust.p12 ^
    -storetype PKCS12 ^
    -storepass Welcome1 ^
    -noprompt


STEP 5 - VERIFY THE NEW CERT
------------------------------
  keytool -list -v ^
    -keystore %DOMAIN_HOME%\security\identity.p12 ^
    -storetype PKCS12 ^
    -storepass Welcome1

Check that:
  - Owner CN shows your current machine name
  - Valid from shows today's date
  - Valid until shows 1 year from now


STEP 6 - UPDATE WEBLOGIC ADMIN CONSOLE
----------------------------------------
1. Open browser -> http://localhost:7001/console
2. Go to Servers -> your server -> Keystores tab
3. Set Keystores to: Custom Identity and Custom Trust
4. Fill in the following:

   Custom Identity Keystore          : C:\...\security\identity.p12
   Custom Identity Keystore Type     : PKCS12
   Custom Identity Keystore Passphrase: Welcome1

   Custom Trust Keystore             : C:\...\security\trust.p12
   Custom Trust Keystore Type        : PKCS12
   Custom Trust Keystore Passphrase  : Welcome1

5. Go to SSL tab and set:
   - Private Key Alias      : (your actual machine name / COMPUTERNAME)
   - Private Key Passphrase : Welcome1

6. Click Save -> Activate Changes


STEP 7 - RESTART WEBLOGIC
---------------------------
  %DOMAIN_HOME%\bin\stopWebLogic.cmd
  %DOMAIN_HOME%\bin\startWebLogic.cmd


==========================================================
NOTES:
- keytool is bundled with the JDK used by WebLogic.
  If keytool is not recognized, add the JDK bin to PATH:
    set PATH=%JAVA_HOME%\bin;%PATH%

- Replace "Welcome1" with your own secure passphrase if desired.

- These are self-signed/demo certs suitable for DEV/TEST only.
  Do NOT use in production.
==========================================================

We will make the SSN Indicator update happen only through the Customer Setup UI, so users must update it directly in the screen. Any SSN Indicator value sent from Bluestar in an inbound message will be ignored. The only time we will use the SSN value from an inbound message is when a brand‑new customer is being created and the action is ADD. After the customer is created, all future SSN updates must be done only through the Customer Setup UI.

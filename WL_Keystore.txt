WEBLOGIC - FIX: CANNOT FIND IDENTITY KEYSTORE ERROR
=====================================================

PROBLEM
--------
WebLogic is looking for certs in:
  %DOMAIN_HOME%\security\

But files were created in:
  %WL_HOME%\server\lib\

FIX: Copy both files to the domain security folder.


STEP 1 - CHECK DOMAIN SECURITY FOLDER EXISTS
---------------------------------------------
  dir %DOMAIN_HOME%\security\


STEP 2 - COPY BOTH FILES
--------------------------
  copy %WL_HOME%\server\lib\DemoIdentity.p12 %DOMAIN_HOME%\security\DemoIdentity.p12
  copy %WL_HOME%\server\lib\DemoTrust.p12 %DOMAIN_HOME%\security\DemoTrust.p12


STEP 3 - VERIFY FILES ARE THERE
---------------------------------
  dir %DOMAIN_HOME%\security\*.p12

You should see both:
  DemoIdentity.p12
  DemoTrust.p12


STEP 4 - START WEBLOGIC
-------------------------
  %DOMAIN_HOME%\bin\startWebLogic.cmd


=====================================================
NOTES:
- No changes needed to config.xml
- config.xml already points to %DOMAIN_HOME%\security\
- Copying files there is all that is needed
=====================================================

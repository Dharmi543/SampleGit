WEBLOGIC - FIX DemoTrust.p12 KEYSTORE PASSWORD ISSUE
======================================================

OPTION 1 - TRY DIFFERENT PASSPHRASES FIRST
--------------------------------------------
Try 1 - Standard WebLogic trust passphrase:

  keytool -list -v -keystore %WL_HOME%\server\lib\DemoTrust.p12 -storetype PKCS12 -storepass DemoTrustKeyStorePassPhrase

Try 2 - Same as identity passphrase:

  keytool -list -v -keystore %WL_HOME%\server\lib\DemoTrust.p12 -storetype PKCS12 -storepass DemoIdentityKeyStorePassPhrase

Try 3 - Blank password:

  keytool -list -v -keystore %WL_HOME%\server\lib\DemoTrust.p12 -storetype PKCS12 -storepass ""

If any of the above works - skip to OPTION 2 to restart WebLogic.


OPTION 2 - IF ALL ABOVE FAIL: DELETE AND RECREATE
---------------------------------------------------
Delete the bad trust store:

  del %WL_HOME%\server\lib\DemoTrust.p12

Recreate it (single line):

  keytool -importcert -alias DemoTrust -file %WL_HOME%\server\lib\DemoCert.crt -keystore %WL_HOME%\server\lib\DemoTrust.p12 -storetype PKCS12 -storepass DemoTrustKeyStorePassPhrase -noprompt

Verify:

  keytool -list -v -keystore %WL_HOME%\server\lib\DemoTrust.p12 -storetype PKCS12 -storepass DemoTrustKeyStorePassPhrase


OPTION 3 - IF DemoCert.crt IS MISSING
---------------------------------------
Re-export the cert from DemoIdentity.p12 first:

  keytool -exportcert -alias DemoIdentity -keystore %WL_HOME%\server\lib\DemoIdentity.p12 -storetype PKCS12 -storepass DemoIdentityKeyStorePassPhrase -file %WL_HOME%\server\lib\DemoCert.crt

Then recreate DemoTrust.p12:

  keytool -importcert -alias DemoTrust -file %WL_HOME%\server\lib\DemoCert.crt -keystore %WL_HOME%\server\lib\DemoTrust.p12 -storetype PKCS12 -storepass DemoTrustKeyStorePassPhrase -noprompt

Verify:

  keytool -list -v -keystore %WL_HOME%\server\lib\DemoTrust.p12 -storetype PKCS12 -storepass DemoTrustKeyStorePassPhrase


FINAL STEP - RESTART WEBLOGIC
-------------------------------
Once both files are verified successfully:

  %DOMAIN_HOME%\bin\stopWebLogic.cmd
  %DOMAIN_HOME%\bin\startWebLogic.cmd


======================================================
NOTES:
- DemoCert.crt must exist before recreating DemoTrust.p12
- Do NOT restart WebLogic until DemoTrust.p12 is verified
- Passphrases:
    Identity : DemoIdentityKeyStorePassPhrase
    Trust    : DemoTrustKeyStorePassPhrase
======================================================

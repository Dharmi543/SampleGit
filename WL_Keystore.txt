WEBLOGIC - RECREATE DEMO CERTS AS PROPER PKCS12 FILES
=======================================================

PROBLEM
--------
WebLogic config.xml expects PKCS12 format files.
Previous files were JKS renamed to .p12 - that does not work.
Recreating as genuine PKCS12 files directly in DOMAIN_HOME\security\


STEP 1 - DELETE OLD/FAKE FILES
--------------------------------
  del %DOMAIN_HOME%\security\DemoIdentity.p12
  del %DOMAIN_HOME%\security\DemoTrust.p12
  del %DOMAIN_HOME%\security\DemoIdentity.jks
  del %DOMAIN_HOME%\security\DemoTrust.jks

  Note: If any file not found - just continue to next step.


STEP 2 - CREATE DemoIdentity.p12 (real PKCS12)
------------------------------------------------
Run as single line:

  keytool -genkeypair -alias DemoIdentity -keyalg RSA -keysize 2048 -validity 365 -storetype PKCS12 -keystore %DOMAIN_HOME%\security\DemoIdentity.p12 -storepass DemoIdentityKeyStorePassPhrase -keypass DemoIdentityKeyStorePassPhrase -dname "CN=%COMPUTERNAME%, OU=Demo, O=Demo, L=Demo, ST=Demo, C=US"


STEP 3 - EXPORT CERT FROM DemoIdentity.p12
--------------------------------------------
Run as single line:

  keytool -exportcert -alias DemoIdentity -keystore %DOMAIN_HOME%\security\DemoIdentity.p12 -storetype PKCS12 -storepass DemoIdentityKeyStorePassPhrase -file %DOMAIN_HOME%\security\DemoCert.crt


STEP 4 - CREATE DemoTrust.p12 (real PKCS12)
---------------------------------------------
Run as single line:

  keytool -importcert -alias DemoTrust -file %DOMAIN_HOME%\security\DemoCert.crt -keystore %DOMAIN_HOME%\security\DemoTrust.p12 -storetype PKCS12 -storepass DemoTrustKeyStorePassPhrase -noprompt


STEP 5 - VERIFY BOTH FILES
----------------------------
Verify Identity:

  keytool -list -v -keystore %DOMAIN_HOME%\security\DemoIdentity.p12 -storetype PKCS12 -storepass DemoIdentityKeyStorePassPhrase

Verify Trust:

  keytool -list -v -keystore %DOMAIN_HOME%\security\DemoTrust.p12 -storetype PKCS12 -storepass DemoTrustKeyStorePassPhrase

Check that:
  - Owner CN shows your current machine name
  - Valid from shows today's date
  - Valid until shows 1 year from now


STEP 6 - START WEBLOGIC
-------------------------
  %DOMAIN_HOME%\bin\startWebLogic.cmd


=======================================================
NOTES:
- Run ALL keytool commands as single lines.
- If keytool not recognized, run first:
    set PATH=%JAVA_HOME%\bin;%PATH%
- Passphrases:
    Identity : DemoIdentityKeyStorePassPhrase
    Trust    : DemoTrustKeyStorePassPhrase
- Files must be created directly in %DOMAIN_HOME%\security\
- Do NOT copy or rename JKS files to .p12
- Do NOT start WebLogic until both files verified.
=======================================================

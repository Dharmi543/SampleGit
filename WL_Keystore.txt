WEBLOGIC - RECREATE DEMO CERTS IN JKS FORMAT
=============================================

REASON
-------
WebLogic default demo settings expect JKS format not PKCS12.
Recreating all certs in JKS format to match default config.


STEP 1 - DELETE ALL OLD PKCS12 FILES
--------------------------------------
  del %DOMAIN_HOME%\security\DemoIdentity.p12
  del %DOMAIN_HOME%\security\DemoTrust.p12
  del %WL_HOME%\server\lib\DemoIdentity.p12
  del %WL_HOME%\server\lib\DemoTrust.p12

  Note: If any file not found - just continue to next step.


STEP 2 - CREATE DemoIdentity.jks
----------------------------------
Run as single line:

  keytool -genkeypair -alias DemoIdentity -keyalg RSA -keysize 2048 -validity 365 -storetype JKS -keystore %DOMAIN_HOME%\security\DemoIdentity.jks -storepass DemoIdentityKeyStorePassPhrase -keypass DemoIdentityKeyStorePassPhrase -dname "CN=%COMPUTERNAME%, OU=Demo, O=Demo, L=Demo, ST=Demo, C=US"


STEP 3 - EXPORT CERT
----------------------
Run as single line:

  keytool -exportcert -alias DemoIdentity -keystore %DOMAIN_HOME%\security\DemoIdentity.jks -storetype JKS -storepass DemoIdentityKeyStorePassPhrase -file %DOMAIN_HOME%\security\DemoCert.crt


STEP 4 - CREATE DemoTrust.jks
-------------------------------
Run as single line:

  keytool -importcert -alias DemoTrust -file %DOMAIN_HOME%\security\DemoCert.crt -keystore %DOMAIN_HOME%\security\DemoTrust.jks -storetype JKS -storepass DemoTrustKeyStorePassPhrase -noprompt


STEP 5 - COPY TO WL_HOME
--------------------------
  copy %DOMAIN_HOME%\security\DemoIdentity.jks %WL_HOME%\server\lib\DemoIdentity.jks
  copy %DOMAIN_HOME%\security\DemoTrust.jks %WL_HOME%\server\lib\DemoTrust.jks


STEP 6 - VERIFY BOTH FILES
----------------------------
Verify Identity:

  keytool -list -v -keystore %DOMAIN_HOME%\security\DemoIdentity.jks -storetype JKS -storepass DemoIdentityKeyStorePassPhrase

Verify Trust:

  keytool -list -v -keystore %DOMAIN_HOME%\security\DemoTrust.jks -storetype JKS -storepass DemoTrustKeyStorePassPhrase

Check that:
  - Owner CN shows your current machine name
  - Valid from shows today's date
  - Valid until shows 1 year from now


STEP 7 - START WEBLOGIC
-------------------------
  %DOMAIN_HOME%\bin\startWebLogic.cmd


=============================================
NOTES:
- Run ALL keytool commands as single lines.
- If keytool not recognized, run first:
    set PATH=%JAVA_HOME%\bin;%PATH%
- Passphrases:
    Identity : DemoIdentityKeyStorePassPhrase
    Trust    : DemoTrustKeyStorePassPhrase
- Do NOT start WebLogic until both files verified.
- JKS is the default format for WebLogic demo certs.
=============================================
